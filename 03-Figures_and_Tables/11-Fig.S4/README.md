# Figure S4 — Comparison of relative effective reproduction numbers

Figure S4 compares relative effective reproduction numbers estimated using
FindPart-w-epsilon with estimates from previous studies for the USA-19 and
UK-141 datasets.

## Panel (a): USA-19

FindPart estimates are obtained from the Table 1 workflow:

    ../09-Table1/best_estimates_with_rri.csv

These estimates are compared with the relative effective reproduction
numbers from Musonda et al., stored in:

    01-USA/musonda2026_USA19_relative_Re.csv

The comparison script is:

    01-USA/compare_musonda_vs_FindPart.R

The baseline lineage KP.3.1.1 is excluded from the Pearson correlation.

## Panel (b): UK-141

FindPart estimates are obtained from the Table 2 workflow:

    ../10-Table2/best_estimates_with_rri.csv

These estimates are compared with the relative effective reproduction
numbers from Kaku et al., stored in:

    02-UK/kaku_2024_UK141_relative_Re.csv

The comparison script is:

    02-UK/compare_Kaku_vs_FindPart.R

The baseline lineage EG.5.1 is excluded from the Pearson correlation.

## Analysis

The comparison scripts match SARS-CoV-2 lineages between the FindPart
estimates and the corresponding previous-study estimates.

For each dataset, the scripts generate:

- a CSV file containing the matched lineage-specific estimates; and
- a CSV file containing the Pearson correlation coefficient, p-value,
  and 95% confidence interval.

The resulting comparison datasets are used by:

    plot_relative_Re_comparison.R

to generate the two-panel supplementary figure.

## Upstream dependencies

The FindPart relative effective reproduction number estimates must first
be available from the Table 1 and Table 2 workflows:

    ../09-Table1/best_estimates_with_rri.csv
    ../10-Table2/best_estimates_with_rri.csv

If either file has been removed using `make clean` in its corresponding
table directory, regenerate that table workflow before running Figure S4.

## Reproducing Figure S4

Run:

    make

This regenerates the USA and UK comparison datasets, Pearson correlation
results, and:

    Fig.S4.tiff

## Generated intermediate outputs

USA:

    01-USA/USA19_Musonda2026_vs_FindPart_relative_Re.csv
    01-USA/USA19_Pearson_correlation.csv

UK:

    02-UK/UK141_Kaku_vs_FindPart_relative_Re.csv
    02-UK/UK141_Pearson_correlation.csv

These files are generated by the workflow and are not required to be
retained in the cleaned repository.

## Cleaning generated files

Run:

    make clean

This removes the generated comparison datasets, Pearson correlation
results, and `Fig.S4.tiff`.

The previous-study input datasets and analysis scripts are retained.

## Software requirements

The workflow requires R.

The comparison scripts use `tidyverse`. Required R packages can be
installed using the repository-level installation script:

    R -f ../../install_packages.R
